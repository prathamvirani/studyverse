# Guide — Typography & Color

## Primary UI font

Use **Inter** as the primary cross-platform interface family.

Reasons:

- excellent readability
- stronger personality than Geist for this product
- reliable on Windows/Linux
- broad variable-font support
- strong numeric/tabular support
- works well with Apple-inspired spacing and controls

## Display serif

Preferred starting point:

- **Instrument Serif**

Use selectively for:

- room titles
- atmosphere quotes
- expressive page titles
- selected large display moments

Do not use serif everywhere.

## Apple fonts

Downloaded SF/New York font files may be used locally as visual reference/mockup material.

Do **not** package them into the website merely because they are available locally.

If web redistribution rights are not explicitly verified, do not ship them.

## Weight guidance

Typical:

- body: 400
- secondary: 400
- controls/buttons: 500
- active nav: 500–600
- titles: 500–600 depending family
- timer/clock numerals: 400–500

Avoid excessive boldness.

## Numeric UI

Use tabular numerals for:

- Pomodoro
- Clock
- playback position
- counters

## Color direction

Move away from current yellow/cream/yellow-green cast.

Use:

- neutral light canvas
- deep neutral dark canvas
- one recognizable Study Space accent
- semantic success/warning/danger
- glass tints influenced subtly by room background

Tokenize:

- background
- surface
- glass
- glass-elevated
- text-primary
- text-secondary
- text-muted
- border-highlight
- accent
- success
- warning
- danger

No scattered hardcoded colors.
